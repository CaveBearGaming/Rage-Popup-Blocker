Popup Blocker is a lightweight browser extension designed to improve browsing experience by reducing intrusive overlays and interruptions on websites. It focuses on detecting and removing common non-essential popups such as cookie consent banners, newsletter prompts, sign-in overlays, and modal dialogs that obscure page content.

The extension works by analyzing page structure in real time and removing or hiding elements that behave like overlay popups, helping pages remain readable and accessible without constant interruptions. It is designed to run automatically in the background on supported websites, requiring no manual configuration for basic use.

Popup Blocker aims to prioritize usability while maintaining compatibility with most websites. It avoids modifying core page content and focuses only on overlay-style elements that disrupt viewing or interaction. Users can continue browsing normally while the extension helps keep pages clean and focused.

This extension is intended for users who prefer a less interrupted browsing experience and want to reduce repetitive popups across the web.
